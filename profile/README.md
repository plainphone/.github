## Plainphone

Plainphone turns an ordinary Android phone into a calm phone: calls, messages, maps and the apps you choose, without social media feeds and games. For a child's first phone, or for an adult who wants to hold themselves to their own rules.

It is free and open source under the Apache License 2.0, and still early: the current releases are test builds.

- [plainphone.org](https://plainphone.org): what it is and how to set up a phone
- [plainphone/plainphone](https://github.com/plainphone/plainphone): the phone app, server, parent apps and filter DNS
- [app.plainphone.org](https://app.plainphone.org): the parent dashboard (test version)

Every feature is checked against our [design principles](https://github.com/plainphone/plainphone/blob/main/docs/design-principles.md): the child can see what the parent sees, monitoring is never hidden, and help is always reachable.
